1. Single-Scale Alignment

The easiest way to align pixels is to do an exhaustive search. By using a scoring engine, we are able to calculate the best displacement for green and red colors to the fixed blue channel. By iterating over every displacement from a [-15,15] window and scoring each one, we are able to find the x and y displacement for the best shift. To counteract the end of the photos, np.roll() is able to wrap the data around to the other side as needed. Additionally, after the first iteration, the colors were still a bit off, inspiring a crop function to make sure the edge of the old photos were not inadvertently offsetting the accurate values. Regardless of if we use the L2 or NCC scoring matrix, we get the same shift values so I personally chose to use the NCC scoring matrix. L2 measures pixel value distances and NCC measures brightness differences, resulting in similar displacement values since a good structural match is also where the brightness matches. The only problem now is that this manual process of shifting the evaluation box is too time consuming for a larger image...

2. Multi-Scale Pyramid Alignment

To solve larger images, a new multi-scale image pyramid algorithm is needed. A downsampling is implemented to handle the large files by filtering then subsampling via a gaussian blur. After the downsampling is implemented, we use it in our pyramid align then recursively call it to find the best shift. Once it is downsampled enough, the single align algorithm from part 1 is run. As the recursion is unpacked, each level doubles the shift and a small pixel search refinement (+/-2) is run around the scaled up resolution, building up the pyramid. This refinement is needed since the earlier downsampling loses sub-pixel precision. This process is ran to align green to blue and red to blue as well to properly colorize the images. However, as you can see, the Emir photo colors are not properly aligned...

3. Failure and Improvements

The Emir photo doesn't work with our alignment strategy derived from pure pixels. This is because the different colors do not have the same brightness level, so instead of using raw brightness, we line up the edges of the color planes. Using cv.Sobel, we are able to get the gradient magnitudes to identify structural edges to align. Adding this edge-based preprocessing step with our scoring engine to the pyramid align allows for a better colorization for Emir and minor GB and RB shifts in the other photos as well.
