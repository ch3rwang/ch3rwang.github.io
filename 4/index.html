1. Visualizing Training and Sampling

1.1 Constructing Noisy Training Inputs

By interpolating a clean image with Gaussian noise, we are able to construct noisy training inputs. With the equation, x_t = (1-t)e + t*x_1 with e sampled from a Normal distribution, we are able to modify the clean image x_1. From t=0 to t=1, we go from a noisy image to the clean on respectively.

1.2 Classical Denoising

By using a Gaussian blur, we are able to reduce noise since the averaging of nearby pixels cancels independent, zero-mean noise. As you can see, at high levels of noise, there are the results aren't as good because the Gaussian blur also removes high frequency (e.g. edges, outlines) when it is removing noise.

1.3 One-Step Denoising

Using a pretrained flow model, we are able to predict the vector field that would point from the noise to our clean image. As we take one sleep in the direction of the vector field, we slowly get a cleaner image that takes the form of whatever our ending clean image is supposed to be. We use the predict_velocity function with a text embedding of "a high quality photo" to compute this vector field.

1.4 Visualizing Velocity

Since we are predicting the vector field, there are areas where it is not on the true trajectory across time steps. By comparing the model to our ground truth velocity vector (x_1 - x_0) using root mean square, we are able to see the areas of struggle.

1.5 Iterative Denoising

To increase our accuracy, we take smaller steps each time, reconstructing a more accurate image because learned flow fied trajectories are usually curved. After every increment (25 steps in total), we recompute velocity, and for the last step, we adjust it so it terminates at t=1 exactly.

2. Conditional Generation and Guidance

2.1 Classifier-Free Guidance

Classifier-free guidance (CFG) will help push trajectories towards a text-conditioned velocity as opposed to just unconditional predictions. When the CFG is ran, a conditional and unconditional velocity is calculated. By setting w, CFG can calculate a weighted direction that will pull the outputs towards the prompt. We set out w to 7. A high w can improve the details of our images (as shown by the comparison between these images and the images from the previous section), but if the w is too high (>10) it can reduce image diversity. We see this sort of happening already with all the humans looking somewhat similar to each other even though they started as different noisy images.

To create a visual anagram, we can average the CFG velocity predicted for one image and CFG velocity predicted for another image (but slipped 180 degrees). For each euler step, we use this average between these stacked images and when the image converges into a clean image, we can see both.

Part B: Flow Matching from Scratch!

Part 1: Training a Single-Step Denoising UNet

1.1 Implementing the UNet, 1.2 Using the UNet to Train a Denoiser

A UNet uses encoders and decoders to denoise and classify images. First, we capture the context of the images on a global context by reducing the resolution. After, we expand it back via upsampling to preserve the tiny details. Using L2 loss optimization, we map a noisy image to its clean image counterpart in the MNIST dataset.

1.2 Using the UNet to Train a Single-Step Denoiser

For every epoch, we generate a fresh noise combination. This will help the model generalize better and avoid overfitting any static artifacts. This is the training data, along with an Adam optimizer, that our denoiser will be following. We have shown the clean/input/prediction after epochs 1 and 5. We have also included the noise levels by rows after this simple training loop. Lastly, we can see how the training loss gets less and less each epoch, as the model leanrs more.

What happens if we use a single-step denoiser (the one we just trained) on noise levels and parameters that are out of distribution. This allows us to better evaluate how degradation levels outside a model's training can be handled and how well it will be handled. As you can see, when it gets to the extremely noisy images, the resulting images are not as clear.

When we try to train a model to denoise pure noise, we can see how the outputs seem to be blurry and does not take the forms of any specific digit. And even after 5 epochs, there is very little change between the outputs. Since we use MSE as our loss function, it tries to minimize the distance from all the training examples. This results in an average of all the images, which causes more pixels in the center (since most handwritten digits will cross the center pixels) to be brighter.

Part 2: Flow Matching Training and Sampling

2.1 Time-Conditioned UNet

Using FCBlock (fully connected block), we are able to be more dynamic during the intermediate stages of our analysis. The FCBlock makes the internal feature map more individualized and scaling each one independently. Based on how noisy our input is, each internal feature such as unflattening and unsampling are scaled dynamically during the process.

2.2 Training the Flow Matching Model, 2.3 Sampling from the UNet

Now we will implement an exponential learning rate scheduler. By predicting the velocity across a linear interpolation path, our optimization target is much smoother than if we just try to predict different jumps. We now take pure Gaussian noise and use the predict velocities to get to clear digits. This contrasts our previous implementation with MSE loss where pure noise didn't really amount to much.

2.4-2.6 Adding Class-Conditioning to UNet then Training and Sampling,

Now we extend our implementation. We add one-hot class labels and a 10% dropout mechanism; the one-hot class label creates a distinct categorical indicator. The block now has class information with time data that gives the model more information about the digit they are generating. We train the model on conditional and unconditional inputs, which were created by randomly replacing inputs in the class vectors to zero during the training process (10% dropout mechanism). This makes it so the model is able to generate with or without guidance during sampling.
