Part 1.1: Convolutions from Scratch!

The convolution pads the image and slides a flipped kernel across the image. By padding the image with half the kernel size, we make sure the kernel can slide over the edge of the image, ensuring our final output has the same dimensions as the original. The 4 for-loop convolution analyzes every pixel, taking the longest. The 2 for-loop implementation uses the summation in the numpy library. 

def conv_4(image, kernel):
    h, w = image.shape
    kh, kw = kernel.shape
    ph, pw = kh // 2, kw // 2
    pad = np.pad(image, ((ph, ph), (pw, pw)), mode="constant")
    kernel = np.flip(kernel, axis=(0, 1))
    result = np.zeros_like(image, dtype=float)
    for i in range(h):
        for j in range(w):
            for u in range(kh):
                for v in range(kw):
                    result[i, j] += kernel[u, v] * pad[i+u, j+v]
    return result


def conv_2(image, kernel):
    h, w = image.shape
    kh, kw = kernel.shape
    ph, pw = kh // 2, kw // 2
    pad = np.pad(image, ((ph, ph), (pw, pw)), mode="constant")
    kernel = np.flip(kernel, axis=(0, 1))
    result = np.zeros_like(image, dtype=float)
    for i in range(h):
        for j in range(w):
            result[i, j] = np.sum(kernel * pad[i: i+kh, j: j+kw])
    return result
By using np.allclose() between the two naive implementations above with the scipy.signal.convolve2d function, we can see that our implementation returns the same values as the built in python version. When using the time library in python, we are able to time how fast each one runs. The 4 for-loop convolution takes 0.000345 seconds while the 2 for-loop convolution takes less time at 0.000241 second. This makes sense the function is not going through the image as slowly as if we went through each pixel like it does for conv_4. The built in convolution function is the fastest at 0.000035 seconds. Part 2.1: Image "Sharpening"

When running a Gaussian, it removes the high frequencies because it is a low pass filter and effectively smooths out rapid changes. We can extract the high frequencies by subtracting the blurred image from the original allows us to isolate the sharp edges and textures again. So in order to sharpen the image again, we can do the inverse and add more of our extracted high frequencies back to the image by multiplying our high frequency mask by a factor of α.

High Pass Filter

Varying the scaling factor α alters how defined the edges and details are. As α values increase, there are sharper edges, greater local contrast, and amplified high-frequency noise. At 2.5, we see the graininess of the image increase and an odd glow around the top of the Taj Mahal. This is why 1.5 was a good scaling factor; it was able to amplify the sharp edges while not having it overpower the image.

Part 2.2: Hybrid Images

For these hybrid images, by making one image a low pass filter and another one a high pass filter, depending on the distance from where you look at the image, you can see one more clearly than the other. The farther you move from the image, the more the high-frequency image fades and the low-frquency aspects become clearly. You can see it in the image of Derek and his cat, Nutmeg. From up close, you can see Nutmeg who is put through the high frequency filter. But if you move away, you see Derek more clearly since he is put through a low frequency filter.

Part 2.3: Gaussian and Laplacian Stacks

Gaussian and Laplacian stacks allow us to break down images into different frequencies without subsampling. A Gaussian stack continuously blurs the image to isolate low-frequencies, while the Laplacian stack subtracts consecutive levels of the Gaussian stack. Here is how these stacks look with the picture of the apple and orange from the paper. By setting up these frequency bands, we are later able to implement the blending of two images.

Part 2.4: Multiresolution Blending (a.k.a. the oraple!)

Taking the Laplacian stack of the images and the Gaussian stack of the mask, we are able to cleanly blend the two images. The Laplacian stack sllows for the apple and orange to be separated into layers of low to high frequencies. The Gaussian stack of the mask smooths out the mask so the transition between the two pictures are not as abrupt as the white and black in the mask itself.
